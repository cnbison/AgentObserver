# 制作流程 SOP 与工具栈

> 配套主方案：[plan.md](plan.md) · 文案库：[copy-bank.md](copy-bank.md) · 视频脚本：[video-scripts.md](video-scripts.md)

---

## 1. 总体流水线

```
策划 → 文案 → 设计 → 视频 → 审核 → 排程 → 发布 → 互动 → 数据复盘
 ▲                                                       │
 └────────────── 下一次迭代反馈 ────────────────────────┘
```

每条内容都要走完一个完整周期，建议按"周"为粒度组织：

| 周一 | 周二 | 周三 | 周四 | 周五 | 周末 |
|---|---|---|---|---|---|
| 选题会 | 文案定稿 | 设计交付 | 视频剪辑 | 审核发布 | 互动运营 |

## 2. 阶段一：选题与策划

### 2.1 工作流

1. 选题会（30 分钟）：从 [plan.md § 3.2 选题清单](plan.md#32-选题角度首批-30-条按热度排序) 选 5–10 条
2. 每条选题填"创意简报"（1 页 A4）：

   ```markdown
   # 选题：____
   目标读者：____
   一句话钩子：____
   平台：____
   类型 / 时长：____
   配图建议：____
   CTA：____
   ```

3. 主编终审 → 入库

### 2.2 工具

| 用途 | 推荐工具 | 备注 |
|---|---|---|
| 选题库 / 看板 | Notion / Trello / Linear | 免费版够用 |
| 灵感收集 | Are.na / Pinterest / Chrome 书签栏 | 维护视觉调性 |
| 协同会议 | 腾讯会议 / Zoom / 飞书 | 屏幕共享 |

## 3. 阶段二：文案

### 3.1 工作流

1. 写作者根据创意简报起草 1000 字初稿
2. 配图占位（先标 `[图：xxx]`）
3. AI 辅助润色（Claude / GPT-4 / 通义千问）
4. 主编终审：标题 + 开头 100 字 + CTA 三处重点检查
5. 入排期库

### 3.2 标题公式

| 类型 | 公式 | 示例 |
|---|---|---|
| 数字型 | 数字 + 关键词 + 钩子 | `900 秒决定一次宇宙观测：AI 比人类更快吗？` |
| 反转型 | 反常识 + 答案 | `不是下围棋：AI 在天文台面对的真实难题` |
| 悬念型 | 问句 | `你的智能体能在 180 个观测夜活下来吗？` |
| 速报型 | 时间 + 事件 | `刚刚：GOSIM 巡天智能体报名通道开启` |
| 教程型 | 如何 + 结果 | `20 分钟跑通基线 12287 分：完整截图` |

### 3.3 工具

| 用途 | 推荐 | 备选 |
|---|---|---|
| 写作 | Notion / iA Writer / Typora | Obsidian |
| AI 润色 | Claude / GPT-4 / 通义千问 / 文心一言 | — |
| 协作 | 飞书文档 / 腾讯文档 / Google Docs | Notion |
| 校对 | Grammarly / 秘塔写作猫 | — |
| 标题生成 | Anyword / Copy.ai / 头条号"爆款标题"工具 | — |

## 4. 阶段三：视觉设计

### 4.1 工作流

1. 设计稿对齐文案（先文字 + 排版骨架，再上色）
2. 主 KV 海报三件套：
   - **1080×1920**（小红书 / 抖音 / 竖屏视频封面）
   - **1920×1080**（B 站 / YouTube / 横屏视频封面）
   - **1080×1080**（微博 / X / Instagram）
3. 字体规范：

   | 场景 | 中文字体 | 英文字体 |
   |---|---|---|
   | 标题 | 思源宋体 / 方正粗雅宋 | Cormorant Garamond / Manrope |
   | 正文 | 思源黑体 / 苹方 | Space Grotesk / Inter |
   | 数字 / 代码 | JetBrains Mono / 等线 | IBM Plex Mono |

4. 三轮评审：草稿 → 内部评审 → 用户评审（5 人小样本）

### 4.2 工具

| 用途 | 推荐 | 价格 | 备选 |
|---|---|---|---|
| **主力设计** | Figma | 免费 / Pro ¥80/月 | Sketch（仅 Mac）、Adobe XD |
| **快速出图** | Canva | 免费 / Pro ¥80/月 | 美图秀秀、创客贴 |
| **AI 配图** | Midjourney / DALL·E 3 / 即梦 AI | $10–60/月 | Stable Diffusion 本地部署 |
| **图标 / 插画** | Iconify / Phosphor Icons / Storyset | 免费 | Flaticon |
| **配色提取** | Coolors / ColorMagic | 免费 | Adobe Color |
| **GIF / 动图** | After Effects + LottieFiles | AE ¥200/月 | GIMP（免费） |

### 4.3 视觉规范速查


## 5. 阶段四：视频制作

### 5.1 工作流

1. **前期**：脚本（[video-scripts.md](video-scripts.md)）→ 分镜 → 镜头清单
2. **中期**：
   - 录屏：OBS / 芦笋录屏 / ScreenFlow
   - 出镜：手机 + 环形灯 + 领夹麦
   - 动画：PPT 导出 / Figma 动画 / After Effects
3. **后期**：
   - 剪辑 → 字幕 → 配乐 → 封面 → 导出
4. **审核**：自审（错别字 / 字幕断行）→ 主编审（事实核查）→ 用户审（5 人小样本）

### 5.2 工具矩阵

| 环节 | 推荐 | 价格 | 备选 |
|---|---|---|---|
| **剪辑（中文）** | 剪映专业版 | 免费 | Premiere Pro ¥100/月 |
| **剪辑（专业）** | DaVinci Resolve | 免费 / Studio ¥2,000 | Final Cut Pro ¥1,998 |
| **录屏** | OBS Studio / 芦笋 | 免费 | ScreenFlow ¥78 |
| **字幕** | 剪映自动字幕 / 网易见外 | 免费 | Descript |
| **封面 / 缩略图** | Figma / Canva | 免费 / ¥80/月 | Photoshop ¥100/月 |
| **动画** | After Effects | ¥200/月 | Cavalry / Motion |
| **背景音乐** | Epidemic Sound / Artlist | $10–15/月 | YouTube Audio Library（免费） |
| **AI 配音** | ElevenLabs / ElevenLabs 中文 | $5–22/月 | 剪映 AI 配音 |
| **数字人** | HeyGen / Synthesia | $24–89/月 | D-ID |

### 5.3 输出规格

| 平台 | 分辨率 | 比例 | 帧率 | 码率 | 时长上限 |
|---|---|---|---|---|---|
| B 站长视频 | 1920×1080 | 16:9 | 30 fps | 6 Mbps | 4 GB |
| B 站 Shorts | 1080×1920 | 9:16 | 30 fps | 4 Mbps | 60 秒 |
| 抖音 | 1080×1920 | 9:16 | 30 fps | 4 Mbps | 15 分钟 |
| YouTube | 1920×1080 / 4K | 16:9 | 30/60 fps | 8–20 Mbps | 12 小时 |
| 小红书视频 | 1080×1440 | 3:4 | 30 fps | 4 Mbps | 5 分钟 |
| X (Twitter) | 1920×1080 | 16:9 | 30 fps | 5 Mbps | 140 秒 |

### 5.4 字幕规范

- 字体：思源黑体 / Source Han Sans
- 大小：B 站 ≥ 36 px / YouTube ≥ 48 px / 抖音 ≥ 42 px
- 颜色：白色主体 + 黑色描边 2 px
- 位置：底部 1/4 处（不挡人脸）
- 关键术语 `choose_action` / `DARK` / `REQUIRED` 用高亮色

## 6. 阶段五：排程与发布

### 6.1 工作流

1. 排期表（Notion / 飞书表格）：

   | 日期 | 时间 | 平台 | 内容 | 负责人 | 状态 |
   |---|---|---|---|---|---|

2. 每条内容建一张"发布卡"，含：
   - 文案（最终版）
   - 配图（最终版）
   - 视频（最终版）
   - 标签 / @ 提及
   - 发布时间

3. 发布前 30 分钟二次核对

## 7. 阶段六：互动与运营

### 7.1 工作流

1. 发布后 2 小时内盯评论，**必回**前 10 条
2. 平台官方互动（点赞 / 转发 / 提问）
3. 私域导流：评论区 / 文末引流到比赛平台
4. 危机应对：负面评论 24 小时内回复；技术问题转给工程团队

### 7.2 工具

| 用途 | 推荐 |
|---|---|
| **评论区聚合** | Buffer Reply / Agorapulse |
| **Discord 运营** | Discord / MEE6 / Carl-bot |
| **微信群运营** | 企业微信 + 群机器人 |
| **用户调研** | 金数据 / 问卷星 / Tally |

## 8. 阶段七：数据复盘

### 8.1 每日复盘（10 分钟）

模板：

```markdown
# 复盘 · ____
## 今日发布：____ 条
## 关键数据：
- 阅读 / 播放 ____
- 互动 ____（赞 + 评论 + 收藏）
- 转化 ____（报名 / 提交 / 关注）
## Top 1 内容：____
## Bottom 1 内容：____
## 明日调整：____
```

### 8.2 每周复盘（60 分钟）

- 当周 KPI 达成率
- Top 3 内容复盘（为什么火）
- Bottom 3 内容（为什么扑）
- 下周选题调整

### 8.3 工具

| 用途 | 推荐 |
|---|---|
| **数据看板** | Notion / Airtable / 飞书多维表格 |
| **BI** | Metabase（免费）/ Tableau / Power BI |
| **GA** | Google Analytics 4 + 自定义事件 |

## 9. 跨平台适配清单

> 每条内容发布前必须做的 7 步。

- [ ] 标题适配（各平台字数限制）
- [ ] 封面图三件套（横 / 竖 / 方）
- [ ] 摘要 / 导语精简到 50 字以内
- [ ] 标签 / Hashtag 5–10 个
- [ ] @ 提及（官方账号 + 合作方）
- [ ] 内部链接 → 比赛平台
- [ ] 版权声明 / 来源标注

### 各平台字数 / 标题限制

| 平台 | 标题字数 | 正文上限 |
|---|---|---|
| 微信公众号 | ≤ 64 字 | 无 |
| 微博 | ≤ 全文 2000 字（标题 28 字） | 2000 |
| 小红书 | ≤ 20 字 | 1000 |
| X (Twitter) | 280 字符（Premium 25k） | 25k |
| 知乎 | ≤ 50 字（标题） | 无 |
| B 站 | ≤ 80 字 | 2000（简介） |
| 抖音 | ≤ 30 字 | 1000 |
| 视频号 | ≤ 30 字 | 1000 |
| LinkedIn | ≤ 200 字 | 3000 |
| Medium | 无硬限（推荐 ≤ 60） | 无 |

## 10. 紧急预案

| 场景 | 应对 |
|---|---|
| 内容审核被卡 | 备稿库至少 3 篇提前 24 小时预审 |
| 比赛平台宕机 | 文案预置应急话术；第一时间公告 |
| 负面评论爆发 | 24 小时内回应 → 私聊 → 转人工 |
| 报名量骤降 | 投放加码 + 种子社群定向推送 |
