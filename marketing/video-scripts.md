## 3. 深度片（15–30 分钟）

> 用途：让策略爱好者看懂赛题与评分公式
> 平台：B 站长视频、YouTube、知乎视频

### 3.1 《`challenge-score-v3` 公式完全拆解》（20 分钟）

#### 结构

| 段 | 时长 | 内容 |
|---|---|---|
| **开场** | 1 分钟 | 自我介绍 + 议题：今天彻底搞懂评分公式 |
| **背景** | 3 分钟 | 巡天任务卡、9 项决策清单、DESI 简述 |
| **公式核心** | 5 分钟 | `A = min(instr·trans·sky / (seeing·airmass), 3.0)` 拆解 + PPT 动画 |
| **bonus 表** | 2 分钟 | DARK / BRIGHT / BACKUP 触发区间表 |
| **总分** | 4 分钟 | `score = base + bonus + reward − penalty` 逐项展开 |
| **实战推算** | 3 分钟 | 用一个真实的候选天区算一遍分数 |
| **答疑** | 2 分钟 | 评论区 / Discord 收集问题现场回答 |

#### 关键画面

- 公式推导用 PPT 动画 + 画外音
- 每个分段用色块标注（`#edb28b` 高亮关键系数）
- 实战推算用 Figma 做动态图

### 3.2 《我的智能体是怎么拿 17000 分的》（20 分钟）

#### 结构

| 段 | 时长 | 内容 |
|---|---|---|
| **开场** | 1 分钟 | 上期预告回顾 + 今天讲策略 |
| **基线回顾** | 2 分钟 | 12287 分是哪些项拿到的 |
| **策略 #1：DARK 优先** | 3 分钟 | 代码 + 跑分对比 +1200 |
| **策略 #2：必做天区优先** | 3 分钟 | 代码 + 跑分对比 +2300 |
| **策略 #3：恶劣天气等待** | 3 分钟 | 代码 + 跑分对比 +1500 |
| **策略 #4：大模型接入** | 3 分钟 | `.env` 配置 + 成本 + 性能 |
| **组合调试** | 3 分钟 | 跑分 17287 的最终配置 |
| **下期预告** | 2 分钟 | 颁奖日专访 + 下届预告 |

- 字体：思源黑体 Bold / 苹方 Bold

- 位置：底部 1/4
- 关键术语高亮：`#edb28b`

| 类型 | 来源 | 备注 |
