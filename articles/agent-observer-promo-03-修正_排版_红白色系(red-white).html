01

INTRO

先用一分钟，认识这场比赛

如果有一天，望远镜不再只是执行人类写好的观测计划，而是能自己观察天空、理解任务进度，并决定下一步看哪里——会发生什么？

这就是 GOSIM Agent Observer（巡天智能体）黑客松 2026 想让开发者亲手挑战的问题。比赛给出的入口很具体：给你的智能体一个 巡天任务 、一片 天空 和 不断变化的天气 ，每隔 900 秒让它决定下一步观测什么。

你不需要拥有望远镜，也不需要先成为天文学家。主办方提供统一的巡天任务、模拟环境、开发工具和评测规则；你要做的是设计一个会观察、会判断、会行动、也会根据环境变化调整策略的智能体。

同一套规则、同一套评测场景，最后比的是：你的智能体，能把这场巡天任务完成得怎么样？


02

WHAT IS THIS

这是一场怎样的比赛？

让 AI 当一晚「主值观测员」

现代巡天望远镜不是「对准一个目标，然后拍下来」那么简单。一个观测夜里， 天气会变 ， 目标会升落 ，不同科学任务对观测条件有不同要求；巡天本身还有自己的完成进度、区域覆盖要求和临时观测请求。

所以观测员真正要回答的问题不是「现在天上有什么可以看」，而是「 在当前条件下，现在看什么最值得 」。一个经验丰富的主值观测员，会不断在科学价值、天气条件、目标可见性、巡天进度和时间成本之间做权衡。

Agent Observer 把这种权衡收敛成一个清晰的 AI 任务： 读取当前状态 → 理解局势 → 比较候选 → 做出观测决策 → 环境继续变化 → 再次决策。每个决策时隙是 900 秒，也就是 15 分钟。你设计的不是一个只回答一次问题的 AI，而是一个在连续环境中持续做决定的 观测智能体 。

— 巡天控制室——观测员面对不断变化的天空条件


03

WHY AGENTS

为什么让 AI 来做这件事？

Agent 的真正挑战在于「 会持续决策 」，而不仅仅是「会回答」。过去我们让 AI 回答问题、写代码、生成内容、调用工具，这些任务大多是孤立的；可一旦 AI 进入真实世界，它面对的就往往是一个 持续变化的环境 ——今天的选择会改变明天的状态，现在省下的时间可能换来下一次更好的机会，一次错误判断也可能让后续计划越来越困难。

巡天观测正好是这样一个干净的实验场。它同时具备几样东西：


不确定性

天气和观测条件会变。


有限资源

每一个 900 秒的时隙都不可逆。


长期目标

整个巡天任务需要持续推进。


多目标权衡

科学价值、优先级和覆盖之间经常打架。


连续决策

每一个动作都会影响后续状态。


可量化结果

最终观测产出可以被统一打分。

「巡天只是场景，连续决策才是核心。」


04

YOUR ROLE

你到底要做什么？

给你的智能体一个「观测员」的位置

比赛提供一套统一的巡天任务和模拟环境。在每个决策时隙，你的智能体都会拿到与当前决策相关的一组信息—— 当前天气与观测条件 、 已发布的天气预报 、 当前巡天任务的完成进度 、 当前可观测的候选天区 ，以及不同观测项目的要求——然后它需要决定下一步做什么。

你的策略可以很简单，也可以逐渐复杂。可以从 规则、排序和启发式方法 起步，也可以再叠加记忆、预测、优化算法或大模型，让 Agent 自己处理更复杂的决策。比赛 不限定技术路线 ，看的是你在统一评测环境里能不能做出更有效、更稳健的连续决策。


05

WHAT'S SPECIAL

这场比赛有什么特别？

① 来自真实科学问题

赛题参考 DESI 等真实巡天任务的公开科学与运行设计，再通过模拟器把复杂决策转化成开发者可以参与的挑战。你不会控制真实望远镜，也不会影响真实科学观测，但你面对的是一个有 真实任务逻辑 的决策环境：天气、时间、目标、任务和巡天进度彼此牵制。这让它既是一场黑客松，也是一次 AI for Science 的决策实验。

② 让 Agent 真正「跑起来」

Agent Observer 把重点放在让你的智能体真正运行一整个模拟巡天任务。一个策略不能只在某一刻看起来聪明，它需要在一整夜里连续面对变化的环境，并让整个巡天任务的结果尽可能更好。你可以反复跑： 运行 → 观察结果 → 找到问题 → 修改策略 → 再运行 。每跑一次，你的智能体都会进化一点。

③ 所有人面对统一的评测环境

正式比赛中，智能体面对的天气、预报和事件不会提前下载给参赛者，你需要 根据当下能拿到的信息做决定 ，而不是提前知道未来的「正确答案」。开发场景和正式评测场景分开，比赛想看的是策略面对新场景时的表现。

④ 结果能被看见，也能被复盘

一次运行结束后你不只是拿到一个分数，平台还会给出 分数分解、逐夜运行结果、决策记录、运行日志 ，以及观测结果的可视化。你可以清楚看到自己的智能体看了哪里、错过了什么、浪费了什么。

THREE QUESTIONS

一个值得你思考的问题

跑通第一次之后，可以先不急着追求复杂模型。试着问自己三个问题：

① 好天气来了，应该把它留给谁？

是优先观测对天气要求更高的目标，还是先完成那些已经接近完成的天区？

② 天气马上要变，应该行动还是等待？

等，可能错过观测机会；马上行动，又可能把更有价值的目标浪费在不好的条件下——什么时候动、什么时候等，本身就是一道题。

③ 你是在做决定，还是只是在执行规则？

真正有意思的是让 Agent 开始理解：为什么现在应该做这个决定？

当你开始想这些问题，你就已经进入了 Agent Observer 的 核心 。

BEYOND ASTRONOMY

这不只是一场天文黑客松

Agent Observer 想探索的并不只是「 AI 能不能做天文 」，它背后更大的问题是：当 AI 进入真实科学工作流，智能体应该如何在复杂环境里 持续观察、规划、行动和修正 ？

巡天之所以是一个非常好的实验场，是因为它同时具备这些特征：明确的长期目标、连续的环境状态、有限的资源、不确定性、多目标权衡、连续决策、可量化的结果，以及可以完整复盘的全过程。这些特征同样出现在 机器人、能源调度、自动化运维、科学计算 以及各种现实世界的 Agent 里。

所以你今天写的可能只是一个「巡天智能体」，但你真正在练习的是让 AI 在一个 持续变化的世界里做出连续决策 。
